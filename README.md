# DSH Mobile

把电脑上的 [DeepSeek Harness](https://github.com/deepseek-ai) 接到手机上。

不是投屏，也不是网页套壳——手机和电脑镜像同一个会话：你在电脑上发起的话题，手机上能接着聊；手机上发的消息，电脑上立刻看到。安卓端是原生 Kotlin + Jetpack Compose 写的。

```
┌─────────────┐        ┌──────────────┐        ┌───────────────────┐
│ 手机 App     │ ─────▶ │ 中转 (relay)  │ ─────▶ │ DSH 桌面版         │
│ Kotlin      │  局域网  │ Node，0.0.0.0 │  本机   │ 127.0.0.1:<随机>   │
└─────────────┘  :8090  └──────────────┘        └───────────────────┘
```

## 为什么需要中转

DSH 桌面版只监听 `127.0.0.1`，而且没有改绑定的开关，手机在任何网络下都连不进来。中转解决的就是这一跳，同时要处理两件它不做就进不去的事：

- **改写 `Origin`**：DSH 会校验来源，不改成 `http://127.0.0.1:<端口>` 一律 403
- **补 `Cookie`**：WebSocket 升级请求不走浏览器那套 cookie，中转要用本机的签名密钥现铸一个，否则 401

第二点是这个项目里最容易踩的坑：漏了它，HTTP 接口都正常、界面能列出来，但一进会话就一直转圈——因为它走的是另一条连接。

## 目录

| 路径 | 是什么 |
|---|---|
| `dsh-mobile/` | 安卓 App（Kotlin + Compose） |
| `dsh-mobile/relay/` | 中转，唯一的实现 |
| `dsh-relay-plugin/` | DSH 插件：让中转跟着 DSH 一起起，挂了自动重启，配置在插件详情页里改 |

## 快速开始

**电脑端**

1. 需要 Node.js 18+ 和 [DSH 桌面版](https://github.com/deepseek-ai)。
2. 装插件（推荐）：把 `dsh-relay-plugin` 装进 DSH 的 profile，它会从自己的位置往上一级找 `dsh-mobile/relay/dsh-relay.mjs`，然后随 DSH 启动中转。

   ```
   dsh plugin --profile desktop add link:<本仓库绝对路径>/dsh-relay-plugin
   ```

   装好后 DSH 的插件页会出现「手机中转」，详情页里能改监听地址、端口、自动重启策略，也能看到访问密钥。

3. 也可以直接跑中转，不装插件：

   ```
   node dsh-mobile/relay/dsh-relay.mjs --host 0.0.0.0
   ```

   它会打印手机该填的地址，以及首次生成时打印一次访问密钥。

**手机端**

用 Android Studio 打开 `dsh-mobile/`，构建安装。或者直接跑：

```
cd dsh-mobile
./gradlew :app:installDebug
```

打开 App，在「连接」页填上电脑的地址（中转启动时会打印，形如 `http://192.168.1.100:8090`）和访问密钥，点连接即可。

## 访问密钥

中转默认会校验密钥：首次启动时在 `~/.dsh/dsh-relay/key.txt` 生成一个 32 位十六进制串，App 连接时必须填对。

- 除了 `/relay/ping`（手机扫网段时用来确认「这台机器上有中转」，只回版本和端口），其余所有请求都要带 `x-relay-key`
- 密钥可以手改，改完重启中转生效
- 浏览器打开 `http://<电脑IP>:8090/` 能看到状态页；带 `?key=你的密钥` 才会显示完整密钥

没有这份密钥的话，同一个 Wi-Fi 下任何人扫到 8090 就能读文件、开会话——这是加它的原因。

## 已知限制

- **必须同一个局域网**。中转绑 `0.0.0.0`，能用的前提是手机能路由到电脑；外网访问要自己解决穿透。
- **流量不加密**（明文 HTTP），密钥本身也是明文传输。只适合可信的局域网上用。
- **依赖 DSH 桌面版在跑**：订阅账号只有桌面形态能用，web/headless 走的是按量 API key。
- 安卓端最低 Android 12（`Modifier.blur` 需要 12+，低版本只是背景图不模糊，其他照常）。
