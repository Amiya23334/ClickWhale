# 点击肥鱼

把电脑上的 [DeepSeek Harness](https://deepseek.com) 接到手机上。

不是投屏，不是网页套壳——**原生安卓客户端**（Kotlin + Jetpack Compose），和电脑镜像同一个会话：你在电脑上发起的话题，手机上能接着聊；手机上发的消息，电脑上立刻看到。

## 为什么不用手机浏览器直接开

DSH 桌面版只监听 `127.0.0.1`，手机本来就连不进去。就算解决了这一层，浏览器里还有两关：

| | 手机浏览器直接开 | 本项目 |
|---|---|---|
| 跨设备访问 | 连不上（只绑回环） | 中转开给局域网 |
| `Origin` 校验 | 403 | 中转改写来源 |
| WebSocket | 401，界面永远「正在加载」 | 中转补 Cookie |
| 界面 | 桌面布局缩到 6 寸屏 | 为手指重排的原生界面 |
| 会话 | 另开一份 | 与电脑同一个会话 |
| 长列表 | 滚动发涩 | 原生 `LazyColumn`，带转场 |

## 界面

这块是刻意做过的，不是套个主题了事。

- **完全可定制**：主题三档（跟随系统 / 夜间 / 日间）、**八套强调色**、字体四档（系统 / 衬线 / 等宽 / **自己的 ttf**）、**自定义背景图**（支持透明 PNG，带模糊和浓度两档）
- **强调色会染到底色里**：切一套色，整个界面的气氛跟着变，不是只有按钮换个颜色
- **深色克制**：层级只用间距和字号，不加边框和阴影——手机要滚长对话，每层实时模糊会掉帧，气泡叠模糊背景对比度也会糊
- **矢量图标**：不用 emoji，跨 ROM 显示一致
- **原生手势与转场**：会话列表 ↔ 聊天是滑动切换，左滑归档带 5 秒撤回

## 会话

- **镜像同一会话**：电脑上发起的，手机上能接着聊
- **实时流式**：token 逐个往外蹦，不是等算完再刷
- **Markdown 渲染**：代码块带高亮，表格、引用、列表正常
- **工具调用折叠**、**思考过程可展开**：默认收起，想看再点，不占屏
- **审批卡片**：需要确认的操作直接在手机上点
- **新建时选工作区**：不用回到电脑前点对话框
- **归档**：左滑收起来，误触有 5 秒撤回

## 文件

- **浏览电脑文件**：不进聊天也能翻目录
- **下载 / 上传**：手机上选文件直接传给电脑
- **切盘符**：C 盘之外的东西也进得去

## 安全

中转默认校验访问密钥：首次启动在 `~/.dsh/dsh-relay/key.txt` 生成一串 32 位密钥，App 连接时必须填对。

- 除 `/relay/ping`（扫网段发现用，只回版本和端口）外，所有请求都要带 `x-relay-key`
- 密钥可手改，改完重启中转生效
- 浏览器打开 `http://<电脑IP>:8090/` 能看到状态页和连接方式

没有这道校验的话，同一个 Wi-Fi 下任何人扫到 8090 就能读文件、开会话。

## 结构

```
┌─────────────┐        ┌──────────────┐        ┌───────────────────┐
│ 手机 App     │ ─────▶ │ 中转 (relay)  │ ─────▶ │ DSH 桌面版         │
│ Kotlin      │  局域网  │ Node，0.0.0.0 │  本机   │ 127.0.0.1:<随机>   │
└─────────────┘  :8090  └──────────────┘        └───────────────────┘
```

| 路径 | 是什么 |
|---|---|
| `dsh-mobile/` | 安卓 App（Kotlin + Compose） |
| `dsh-mobile/relay/` | 中转，唯一的实现 |
| `dsh-relay-plugin/` | DSH 插件：让中转跟着 DSH 起、挂了自动重启，配置在插件详情页里改 |

## 快速开始

**电脑端**

1. 需要 Node.js 18+ 和 [DSH 桌面版](https://github.com/deepseek-ai)。
2. 装插件：双击 `dsh-relay-plugin/install.cmd`，或者

   ```
   dsh plugin --profile desktop add link:<本仓库绝对路径>/dsh-relay-plugin
   ```

   装好后 DSH 的插件页会出现「点击肥鱼 · 中转」，详情页里能改监听地址、端口、自动重启策略，也能看到访问密钥。

   > 中转只随插件启动。别手动 `node` 再起一份——两边都管着 8090，多起的那个只会撞 `EADDRINUSE`，然后出现「端口有人在听但界面显示已停止」。

**手机端**

用 Android Studio 打开 `dsh-mobile/` 构建安装，或者：

```
cd dsh-mobile
./gradlew :app:installDebug
```

打开 App，在「连接」页填上电脑地址（中转启动时会打印，形如 `http://192.168.1.100:8090`）和访问密钥。

## 已知限制

- **必须同一个局域网**。中转绑 `0.0.0.0`，前提是手机能路由到电脑；外网访问要自己解决穿透。
- **流量不加密**（明文 HTTP），密钥也是明文传输。只适合可信的局域网。
- **依赖 DSH 桌面版在跑**——订阅账号只有桌面形态能用。
- 安卓最低 12；低版本上背景图不会模糊，其他照常。
